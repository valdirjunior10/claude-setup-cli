# Contribuindo

Este repositório é mantido e mudado só pelo autor. **Pull Requests não são
aceitos** — se você tem uma sugestão, use as Issues pra descrever o que
gostaria de ver, mas não há garantia de que vai ser implementado.

Sinta-se livre pra:
- Usar o CLI como está
- Fazer fork e adaptar pra sua própria necessidade (a licença MIT permite)

O que não acontece aqui:
- Merge de PR de terceiros
- Revisão de código de fork externo
- Compromisso de roadmap ou suporte
